How this actually works

Two tiers, doing genuinely different jobs. Tier 1 catches tone. Tier 2 catches the thing that actually matters: agreement that tracks pressure instead of evidence.

Tier 1 - surface flattery

Free, offline, always on. Scores how much a response leans on unearned validation phrasing ("you're absolutely right," "great question"). This is tone-matching only - it cannot tell you whether an agreement was warranted.

Tier 2 - position-reversal judge

Opt-in, your own API key. Finds moments where the AI reversed a claim right after user pushback, then asks: did the user actually provide new evidence, or just pressure? Only a reversal with no new evidence gets flagged.
